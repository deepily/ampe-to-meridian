# Meridian: Live GCP Deploy + Simplification Pass

## Context

Meridian is a GCP-native ML pipeline for student retention prediction (replacing the AMPE project). The prior migration (2026-04-01) delivered all 5 phases + completion work in a single day: 8 Terraform modules, 13 KFP v2 pipeline components, FastAPI serving, 103 tests passing, CI/CD, chaos suite, and docs. Everything is code-complete and committed (`f1c77fd`).

**But**: nothing has been deployed. Exploration surfaced three gaps:

1. **No root Terraform composition exists** — the 8 modules live in `infrastructure/modules/` but nothing instantiates them together. `infrastructure/shared/backend.tf` and `providers.tf` are stranded. `make deploy` targets `infrastructure/environments/dev/` which is a nonexistent directory. **`make deploy` cannot work as-is.**
2. **Existing BQ data is unmanaged** — 50K rows + 4 tables exist in project `ampe-to-meridian` from an ad-hoc Python load script. They are NOT in tfstate and WILL cause `terraform apply` to 409 on the dataset creation.
3. **Tfstate bucket chicken-and-egg** — `backend.tf` points to `meridian-tfstate-dev-<project>`, but the `storage` module creates that same bucket. Must be bootstrapped before `terraform init`.

The codebase was built rapidly, so a code-quality audit identified ~190 LoC of duplication that can be cleaned up (mkdir boilerplate, parquet I/O, magic numbers, logger boilerplate). Effort: ~5–6 hours.

**User decisions**:
- Deploy all 8 modules + add `enable_api` flag so GLB is togglable via tfvars
- Drop existing BQ data and recreate via Terraform (preserves CMEK/partitioning contract)
- Deploy first, then simplification pass
- ADC auth + billing already set up

**Intended outcome**: A live Meridian stack on project `ampe-to-meridian` with all 8 modules in tfstate, a Vertex AI pipeline run that completes end-to-end, and a cleaner codebase afterward.

### Task S.1: I/O utilities (~1.5 hours, ~60 LoC saved)

**Create `src/utils/io_utils.py`**:
```python
def ensure_parent_dir( path: str ) -> None:
    """Ensure parent directory of path exists.

    Requires:
        - path is a non-empty string (file path)

    Ensures:
        - os.path.dirname( path ) exists as a directory
        - no-op if parent is "" (current dir)
    """
    os.makedirs( os.path.dirname( path ) or ".", exist_ok=True )

def read_parquet( path: str ) -> pd.DataFrame:
    """Read component-input parquet file."""
    return pd.read_parquet( path )

def write_parquet( df: pd.DataFrame, path: str ) -> None:
    """Write component-output parquet, creating parent dirs."""
    ensure_parent_dir( path )
    df.to_parquet( path, index=False )
```
